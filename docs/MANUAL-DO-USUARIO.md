# 🕐 1. PLANTÃO

O **Plantão é o centro do contexto operacional do turno**.

### ▶️ Iniciar

1. Acesse **Plantão**.
2. Confira se já existe um plantão aberto.
3. Se necessário, inicie um novo plantão.
4. Confira operador, supervisor, equipe e demais dados.
5. Só então prossiga para a operação.

### 🔄 Durante o plantão

Mantenha atualizados:

- equipe e guarnições;
- viaturas;
- atividades e informativos;
- ocorrências relacionadas ao turno;
- movimentação de itens;
- observações importantes;
- **Atualização em tempo real**.

> **Importante:** Atualização em tempo real pertence ao **Plantão**, não ao módulo Ocorrências.

### 🚔 Guarnição das viaturas

Ao inserir integrantes em uma viatura:

- os integrantes permanecem vinculados durante o plantão;
- ao editar a viatura, os integrantes atuais devem aparecer;
- é possível remover ou alterar a composição;
- ao encerramento do plantão, o vínculo daquele turno é finalizado.

### 🔒 Encerrar

Antes de encerrar:

- confira ocorrências;
- confira viaturas;
- confira itens retirados;
- confirme devoluções;
- revise observações;
- confira o relatório;
- finalize o plantão.

Depois, confirme em **Histórico**.

# 📞 2. OCORRÊNCIAS

## ➕ Abrir

Acesse **Nova** e preencha os dados solicitados.

Priorize:

**Natureza → Prioridade → Local → Solicitante → Relato → Envolvidos**

> **Regra de ouro:** registre fatos objetivos. Não invente informações.

## 🚔 Despachar

1. Abra a ocorrência.
2. Localize o despacho.
3. Selecione uma viatura disponível/elegível.
4. Confirme.
5. Acompanhe o atendimento.

## 📍 Registrar chegada

Quando a equipe chegar:

1. abra a ocorrência;
2. registre **Chegada**;
3. confira o horário;
4. continue o atendimento.

## 📝 Atualizar

Registre os fatos conforme acontecem, mantendo a sequência cronológica.

## ✅ Encerrar

Antes do encerramento:

- confira o desfecho;
- registre observações necessárias;
- confira horários;
- confirme os dados;
- encerre a ocorrência.

### 🖨️ Boletim

Quando disponível:

**Ocorrência → Visualizar/Imprimir boletim → conferir → imprimir ou salvar em PDF**

---

# 🚔 3. VIATURAS

Utilize **Viaturas** para consultar o recurso e sua situação operacional.

Confira:

- prefixo;
- placa;
- modelo;
- guarnição;
- status;
- disponibilidade;
- quilometragem.

### 👥 Guarnição

A composição da viatura deve refletir a operação real.

**Editar viatura → conferir integrantes atuais → adicionar/remover conforme necessário → salvar**

> Integrantes ativos cadastrados em **Equipe** podem ser vinculados à viatura conforme as regras do plantão.

---

# 👮 4. EQUIPE

Use **Equipe** para consultar o efetivo cadastrado.

Informações comuns:

- nome;
- matrícula;
- tipo;
- função;
- situação ativa/inativa.

> Alterações cadastrais devem ser realizadas somente por usuários autorizados.

---

# 📍 5. POSTOS FIXOS

Use **Postos fixos** para consultar locais cadastrados.

Pesquise por:

- nome/tipo;
- bairro;
- endereço;
- filtros disponíveis.

As informações podem incluir responsável, telefone, horário, cobertura e observações.

---

# 🎒 6. ITENS

O menu **Itens** reúne:

### 🔫 Armas
**Cadastrar → retirar → responsável → utilizar → devolver → conferir histórico**

### 📻 Rádios
**Identificar → retirar → responsável → utilizar → devolver → conferir**

### 🖥️ CAD
Utilize para controle dos itens cadastrados e registre corretamente situações como:

**OK · AVARIADO · EXTRAVIADO · AUSENTE**

> [!WARNING]
> Um item com movimentação aberta não deve ser tratado como disponível para uma nova retirada.

### 🔎 Rastreabilidade

O sistema deve permitir responder:

**Qual item? → Quem? → Quando? → Qual plantão? → Devolvido? → Quando?**

---

# 📊 7. RELATÓRIOS

Use **Relatórios** para consultas e análise.

Fluxo recomendado:

**Selecionar filtros → conferir período → consultar → analisar → utilizar o resultado**

O relatório apoia a gestão; ele não substitui o registro operacional original.

---

# 📚 8. HISTÓRICO

Use **Histórico** para consultar plantões encerrados.

### 🔎 Localizar

1. Abra **Histórico**.
2. Selecione o período, quando aplicável.
3. Atualize a consulta.
4. Localize o plantão.

### 👁️ Visualizar

**Visualizar** é destinado à consulta/documentação.

### ✏️ Editar

**Editar** é destinado a alterações quando o perfil possuir autorização.

### 🖨️ Relatório

Abra a visualização do plantão, confira o conteúdo e utilize a impressão do navegador ou **Salvar como PDF**.

---

# 👤 9. PERFIL E USUÁRIOS

## Meu perfil

Utilize sua própria conta e mantenha os dados corretos.

Nunca compartilhe sua senha.

## Usuários

Área administrativa, quando disponível.

Administradores podem possuir funções ampliadas, como:

- consultar usuários;
- aprovar/rejeitar cadastros;
- administrar perfis;
- executar ações administrativas autorizadas.

> [!CAUTION]
> Conceda somente o nível de acesso necessário para cada usuário.

---

# 🔐 10. SEGURANÇA OPERACIONAL

### ❌ Nunca

- compartilhe sua senha;
- use a conta de outro agente;
- deixe a sessão aberta em equipamento compartilhado;
- registre informação falsa;
- altere registros para esconder erros;
- envie dados operacionais a destinatários não autorizados;
- tente contornar permissões pela URL ou ferramentas do navegador.

### ✅ Sempre

- use sua própria conta;
- confira antes de salvar;
- registre fatos objetivamente;
- proteja informações operacionais;
- comunique erros;
- comunique suspeitas de acesso;
- confira os itens no início e no fim do plantão.

# 🆘 12. SE ALGO DER ERRADO

### Não consigo entrar
Confira:

**e-mail → senha → confirmação → aprovação → conexão → atualização da página**

### Plantão não aparece no Histórico
Confira:

**período → encerramento → atualização → permissão**

### Não consigo despachar uma viatura
Confira:

**status → disponibilidade → outro atendimento → permissão**

### Não consigo retirar arma/rádio
Confira se existe **movimentação aberta** ou se o item está indisponível.

### Uma função desapareceu
Confira seu **perfil/permissão**.

> [!WARNING]
> Se uma operação sensível apresentar erro, evite repetir várias vezes. Anote o horário, a ação realizada e a mensagem exibida e comunique a administração/técnico responsável.
